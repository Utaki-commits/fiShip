# 旭波 — Kyokuha デザインコンセプト

## コンセプト名
旭波（Kyokuha）  
旭日の放射＋波紋。朝日が海面に広がる瞬間の力強さと静けさ。  
漁師が毎日触れる「道具」として設計された、洗練された和の現代UI。

## コアバリュー
- 潔さ：余白を活かす。引き算の美学。1画面に情報を詰めない。
- 力強さ：朱赤の存在感。迷いのない大きなタップ対象。はっきりとした状態表示。
- 信頼感：毎日使える安定感。和紙の温かみ。過剰な装飾をしない誠実さ。

## タイポグラフィ原則
- 使うウェイト：400（Regular）と 500（Medium）のみ。600・700 禁止。
- スケール：26px / 19px / 15px / 12px / 11px
- ラベルに letter-spacing: 0.03em
- 行間（line-height）：1.7
- ALL CAPS 禁止

## 形状言語
- カード角丸：12px
- ボタン角丸：9px
- バッジ・pill：20px
- インプット：8px
- ボーダー太さ：0.5px（強調時のみ 1.5px。2px 禁止）
- ボーダー色：#E8DDD8

## 旭日モチーフルール
- 使用箇所：ヘッダー背景のみ
- 白線・opacity 0.10〜0.15
- 中心点は画面外（下方）に配置
- カード内・ボタン上では使わない

## 禁止事項（全AI共通）
- グラデーション・シャドウ・blur 禁止
- font-weight 600・700 禁止
- 2px border 禁止（選択時も 1.5px まで）
- ALL CAPS テキスト禁止
- 純白（#FFFFFF）を画面背景にしない（washi-50 を使う）
- トークン外の色を勝手に使わない
- 1画面に情報を詰めすぎない

## 各AIへの引き継ぎ定義
- Figma：上記トークンを Local Variables に登録。旭日モチーフはコンポーネント化。
- Uizard：このコンセプトを読んでラフ案生成。朱赤×和紙白の配色を優先。
- v0：Tailwind + shadcn/ui。トークンをCSS変数として使用。weight は 400・500 のみ。
- Codex：v0出力を実装化。トークン外の色・weight・border幅は全てリジェクト対象。
