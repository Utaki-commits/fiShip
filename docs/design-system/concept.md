# fiShip デザインコンセプト

## コンセプト名
信頼・安心・プロフェッショナル

旧コンセプト「旭波（Kyokuha）」は廃止する。
今後のUIは、ネイビー・ダークグリーン・シルバーを基調にした落ち着いた業務品質のデザインに統一する。

## コアバリュー
- 信頼：ヘッダーはダークネイビーで、安定感とプロフェッショナル感を出す。
- 安心：背景は緑みのオフホワイトで、長時間見ても疲れにくい画面にする。
- 明快：メインCTAはダークグリーンに統一し、次に押す操作を迷わせない。
- 誠実：装飾を増やさず、薄いシルバーの境界線で情報を整理する。

## カラートークン

CSS変数として以下を正とする。
新規実装・既存改修では、旧「旭波」トークンを使わない。

```css
:root {
  --color-bg:      #F4F6F2; /* 背景：緑みオフホワイト */
  --color-header:  #1B2A4A; /* ヘッダー：ダークネイビー */
  --color-cta:     #1E4D3A; /* メインCTA：ダークグリーン */
  --color-accent:  #8A9BB5; /* アクセント：シルバー */
  --color-border:  #CDD3DC; /* ボーダー：薄いシルバー */
  --color-text:    #1A2420; /* テキスト：ほぼ黒 */
  --color-subtext: #5A6A78; /* サブテキスト：グレー */
}
```

| トークン | 値 | 用途 |
|---|---:|---|
| `--color-bg` | `#F4F6F2` | 画面背景 |
| `--color-header` | `#1B2A4A` | ヘッダー背景 |
| `--color-cta` | `#1E4D3A` | 保存・登録・送信などのメインCTA |
| `--color-accent` | `#8A9BB5` | 補助的な強調、アイコン、区切り |
| `--color-border` | `#CDD3DC` | カード・入力欄・区切り線 |
| `--color-text` | `#1A2420` | 主テキスト |
| `--color-subtext` | `#5A6A78` | 補足テキスト、説明文 |

## UIルール

- ヘッダー背景は `#1B2A4A` を使う。
- CTAボタン背景は `#1E4D3A` を使う。
- 画面背景は `#F4F6F2` を使う。
- カード背景は白を基本とし、境界線は `0.5px solid #CDD3DC` にする。
- 入力欄の境界線は `0.5px solid #CDD3DC` にする。
- `font-weight` は `400` と `500` のみ使う。`600` と `700` は禁止。
- shadowは禁止。
- gradientは禁止。
- blurは禁止。
- 角丸は既存ルールを維持し、カードは12px、ボタンは9px、入力欄は8pxを基本にする。
- タップ対象はpadding 14px以上を基本にする。

## ボタンルール

### メインCTA
- 背景：`#1E4D3A`
- 文字：白
- border：なし
- border-radius：9px
- padding：14px以上
- font-weight：500

### セカンダリボタン
- 背景：transparent または白
- 文字：`#5A6A78`
- border：`0.5px solid #CDD3DC`
- border-radius：9px
- font-weight：500

### 編集・補助操作
- 背景：白
- 文字：`#1E4D3A`
- border：`0.5px solid #CDD3DC`
- border-radius：9px
- font-weight：500

## カードルール

- 背景：白
- border：`0.5px solid #CDD3DC`
- border-radius：12px
- shadowは使わない。
- カードを入れ子にしない。
- 1画面に情報を詰め込みすぎない。

## タイポグラフィ

- 使用ウェイト：400 / 500のみ。
- 600 / 700は禁止。
- 主見出し：24px前後、500。
- セクション見出し：18px前後、500。
- 本文：15px〜16px、400。
- 補足：12px〜14px、400。
- line-heightは1.6〜1.8を基本にする。

## 禁止事項

- 旧「旭波（Kyokuha）」コンセプトへの言及を新規UI判断に使わない。
- 旧カラー `#7F1D1D`、`#B91C1C`、`#F7F2EF` を新規UIの基準色として使わない。
- shadowを使わない。
- gradientを使わない。
- blurを使わない。
- `font-weight: 600` / `700` を使わない。
- `2px border` を使わない。
- トークン外の色を勝手に増やさない。
