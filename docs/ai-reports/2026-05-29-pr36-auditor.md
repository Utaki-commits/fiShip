## Architecture Auditor

**判定**: 🟡 YELLOW
**概要**: SNSメッセージ件数取得でvessel_id絞り込みあり・主要ロジックは問題ないが、ナビ文言変更・date_format型のUI文言など複数の確認推奨事項あり

- [YELLOW] ボトムナビの文言を '📋 予約' → '📋 出船予定'、'📞 電話メモ' → '📞 予約登録' に変更している。既存の文言を変更する場合は仕様書・Figmaとの整合性確認が必要。共通禁止事項「既存の文言を別の文言に変えている」に該当する可能性がある。 (src/app/dashboard/layout.tsx)
- [YELLOW] sns_messages テーブルを新規に参照しているが、このテーブルの存在・スキーマ（vessel_id, channel, status カラム）が既存DBに定義済みか確認が必要。推測でテーブル名・カラム名を使っているリスクがある。 (src/app/dashboard/page.tsx)
- [YELLOW] vessels テーブルに新カラム（captain_name, banner_url, date_format）を追加参照しているが、DBマイグレーションがこのPRに含まれていない。カラムが存在しない場合エラーになる可能性がある。 (src/app/dashboard/page.tsx, src/app/dashboard/account/page.tsx)
- [YELLOW] Promise.all の分割代入で `{ count: lineCount }` と `{ count: instagramCount }` を受け取っているが、countがnullの場合のフォールバック（|| 0）は対応済み。ただし、sns_messagesテーブルが存在しない場合のエラーハンドリングがなく、失敗時にdashboard全体のデータ取得が止まる可能性がある。 (src/app/dashboard/page.tsx)
- [YELLOW] heroヘッダーにメニューボタンのみが配置され、h1タイトルが省略されている。hero propがある場合にページタイトルがDOMに存在しないため、アクセシビリティ・スクリーンリーダー対応の観点で確認が必要。 (src/app/dashboard/_components/CaptainShell.tsx)

## UX Auditor

**判定**: 🟡 YELLOW
**概要**: ナビゲーション文言変更・SNSテーブル参照・和暦設定追加など概ね問題ないが、既存ナビラベル変更と新規テーブル名確認が必要

- [YELLOW] ナビゲーションのラベルを「予約」→「出船予定」、「電話メモ」→「予約登録」に変更している。既存ユーザーが慣れ親しんだ文言を無断で変更することは共通禁止事項（既存の文言を別の文言に変えている）に該当する可能性があり、意図的な変更かどうか人間確認が必要。 (src/app/dashboard/layout.tsx)
- [YELLOW] `sns_messages` テーブルへのクエリを追加しているが、このテーブル名・カラム名（channel, status, 'unprocessed'）が既存のスキーマに存在するか確認が取れない。推測で追加した場合、架空テーブルへのクエリとなりエラーが発生する。 (src/app/dashboard/page.tsx)
- [YELLOW] `date_format` カラムが `vessels` テーブルに存在するか確認が必要。既存スキーマにないカラムを推測で追加している可能性がある。 (src/app/dashboard/account/page.tsx)
- [YELLOW] `captain_name` および `banner_url` カラムのスキーマ存在確認が必要。推測によるカラム名追加の可能性がある。 (src/app/dashboard/page.tsx)
- [YELLOW] アカウント設定ページのボタン（フォントサイズ選択・日付形式選択）にローディング・disabled状態が実装されていない。非同期保存中に連打できる状態になっている。 (src/app/dashboard/account/page.tsx)
