# Auditor レポート — PR #29

**日時**: 2026-05-25
**PR**: fix: バナー縮小・便カードレイアウト・CTAボタン固定
**総合判定**: 🟡 Yellow — 人間確認推奨

## Architecture Auditor

**判定**: 🟡 YELLOW
**概要**: CTAボタン固定化など概ね改善だが、ボタン高さ未確認・便名フォントサイズ縮小・終了時刻情報の欠落が要確認

- [YELLOW] 固定CTAボタンの高さが `padding: '16px'` のみで明示的な `minHeight` が指定されておらず、44px未満になる可能性がある。UXルールでは主要CTAは推奨64px（最低56px）。元実装では `minHeight: '64px'` が付いていたが削除されている。 (src/app/reserve/[vesselId]/page.tsx)
- [YELLOW] 便名の fontSize が `21px` から `16px` に縮小された。重要情報が小さくなり、屋外スマートフォン使用の船長・乗船客にとって視認性が低下する懸念がある。 (src/app/reserve/[vesselId]/page.tsx)
- [YELLOW] 元実装にあった終了時刻表示（`bin.setting.end_time ? ` - ${bin.setting.end_time} 終了予定` : ''`）が削除されており、乗船客が釣行終了時刻を確認できなくなっている。情報の欠落として確認推奨。 (src/app/reserve/[vesselId]/page.tsx)

## UX Auditor

**判定**: 🟡 YELLOW
**概要**: 主要CTAの画面下部固定化は改善だが、ボタン高さが56px未満になった可能性とfont-weight:700使用有無の確認が必要

- [YELLOW] 固定CTAボタンのminHeightが削除され、padding: '16px'のみになった。フォントサイズ16pxでpadding上下16pxの場合、ボタン高さが約48px程度になり推奨56px（主要CTA推奨64px）を下回る可能性がある。minHeight: '56px'以上を明示的に指定することを推奨。 (src/app/reserve/[vesselId]/page.tsx)
- [YELLOW] 便名（getBinName）のフォントサイズが21px→16pxに縮小された。重要情報のフォントサイズ縮小は屋外・低ITリテラシーユーザーの視認性を下げる懸念がある。14px以上ではあるが、視認性の観点で人間確認を推奨。 (src/app/reserve/[vesselId]/page.tsx)
- [YELLOW] 固定CTAボタンの背景色 '#F4F6F2' および '#1E4D3A' がCSS変数（var(--surface), var(--ocean)など）を使わずハードコードされている。既存コードからの踏襲の可能性もあるが、デザイントークンの統一観点で確認推奨。 (src/app/reserve/[vesselId]/page.tsx)
