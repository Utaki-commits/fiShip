# 船長向け業務管理UIの問題点

## カラーの一貫性
- **ステータス表示の色が不統一**: 「重要度速報」(赤背景)、「貸切問い合わせ」(黄色背景)、「未連絡」(オレンジ色)など、警告レベルの色分けルールが不明確
- **「昼便」ラベルの青色**: 既存の3名と1名で同じ青色を使用しており、状態の違いが判別できない

## 文字サイズ
- **お客様名と日付情報のコントラスト不足**: 名前と予約日時が同じような文字サイズで、重要情報が埋もれている
- **「今すぐ電話する」ボタンの文字**: 海上での視認性を考慮すると、やや小さい可能性

## タップ領域
- **「詳細を見る」ボタンが小さすぎる**: 海上での揺れを考慮すると、タップミスが発生しやすいサイズ
- **カード全体とボタンの関係が不明確**: カード自体がタップ可能なのか、ボタンのみなのか判別しづらい

## 情報の優先順位
- **対応待ち件数の表示位置**: 画面上部に6件の対応待ちがあるが、下にスクロールしないと詳細が見えず、緊急度が伝わりにくい
- **重要度速報の佐藤花子様**: 最も緊急性が高いはずだが、リスト中央に配置されており見落とす危険性

## CAPTAIN_UX_DNA違反
- **揺れる環境での誤操作リスク**: 「昼便の出船を中止する」ボタンが赤枠のみで、重大な操作にしては誤タップ防止策が不十分
- **片手操作の困難性**: 上部の対応待ち件数と下部の出船情報が離れすぎており、海上での片手操作時に画面全体を把握しづらい
