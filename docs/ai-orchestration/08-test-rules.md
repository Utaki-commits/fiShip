# Test Rules

## Playwrightテスト基準

- スマホ幅で確認する。
- 基準ビューポート:
  - 幅 `390px`
  - 高さ `844px`
- 主要操作はタップで確認する。
- 画面遷移、フォーム入力、エラー表示、処理中表示を確認する。
- 文字が重ならないことを確認する。
- ダークモード対象画面ではライト/ダーク両方を確認する。
- 予約ページは端末の `prefers-color-scheme` に従うことを確認する。

## テストすべき画面一覧

- `/login`
  - 初期表示。
  - LINEログインボタン。
  - 電話番号ログインへの切替。
  - OTP入力画面。
  - 規約リンク。
- `/register`
  - 3ステップ入力。
  - 必須エラー。
  - エリア選択から都道府県選択。
  - 完了画面。
- `/dashboard`
  - ヘッダー。
  - 承認待ち件数。
  - 今日・明日の予約カード。
  - TEL、連絡済み、編集、取消、削除。
- `/dashboard/bookings`
  - カレンダー。
  - 予約カード。
  - 編集モーダル。
  - 削除確認モーダル。
  - キャンセル済み表示。
- `/dashboard/bookings/new`
  - メモ入力。
  - 補足情報details。
  - 解析結果。
  - 必須項目不足時の登録ボタンdisabled。
  - オフライン保存メモ表示。
- `/dashboard/schedule`
  - 釣行プラン一覧。
  - 便追加/編集。
  - 休船日追加/削除。
  - 受付中止/再開。
- `/dashboard/vessel`
  - 予約リンク。
  - QRコード。
  - 船情報編集。
  - 設備カテゴリ。
- `/reserve/[vesselId]`
  - 船ヘッダー。
  - カレンダー。
  - 便選択。
  - 残席表示。
  - 予約フォーム。
  - 満員、貸切、休船日の表示。
  - 予約完了/予約リクエスト完了。

## テストすべき操作一覧

- ログイン導線:
  - LINEログインボタン押下。
  - 電話番号入力。
  - OTPコード入力。
- 登録:
  - 未入力で次へ。
  - すべて入力して登録。
- 予約管理:
  - 承認待ちを承認。
  - 承認待ちをお断り。
  - TELボタンで `tel:` が発火する。
  - 未連絡/連絡済み切替。
  - 予約編集保存。
  - 予約取消。
  - 予約削除。
- 予約ページ:
  - 過去日は選択できない。
  - 満員日は予約できない。
  - 貸切期間は選択できない。
  - 電話番号不正時にエラー。
  - 人数超過時にエラー。
- スケジュール:
  - 便を作成。
  - 同名便を拒否。
  - 曜日未選択を拒否。
  - 休船日を作成。

## 合格基準

- 画面が白紙にならない。
- Consoleに致命的なエラーが出ない。
- 主要CTAが56px以上ある。
- 文字がボタンやカードからはみ出さない。
- ライト/ダークで文字が読める。
- 予約カードに必要情報が表示される。
- API失敗時に日本語エラーが出る。
- push後にGitHub mainで変更が確認できる。
- push後にVercelデプロイが成功している。

## 禁止事項

- PC幅だけで確認しない。
- Consoleエラーを無視しない。
- スクリーンショット確認なしで大きなUI変更を完了扱いにしない。
- 予約作成や削除などの副作用を本番データで不用意に実行しない。
- 環境変数の値をテストログに出さない。
