## タスク2: STEP 1 - 船情報 + カレンダー

### 船情報エリア

```
[バナー画像（banner_url）]
[船名]  [詳細を見る →]  ← 設備詳細ページへ遷移（別ページ）
船長 [船長名]
─────────────────────
📍 [港名]  💴 [料金]〜/名
─────────────────────
基本設備（常時表示）：
駐車場・トイレ・ライフジャケット貸出のみ
あり/なし/有料をアイコン+テキストで表示
```

### カレンダー

月ナビゲーション（前月・次月）付きのカレンダーを表示。

**セルの表示ルール：**

| 状態 | 表示 | 背景色 | タップ |
|---|---|---|---|
| 空き（定員50%以上） | ○（緑） | #FFFFFF | 可 |
| 残りわずか（定員50%未満） | 残席数（①②③...） | #FEE2E2 | 可 |
| 予約できない（満員・休船・チャーター交渉中） | × | #E5E7EB | 不可 |
| 過去日 | グレーアウト | #F3F4F6 | 不可 |
| 選択中 | 朱赤枠 | - | - |

**凡例（必ず表示）：**
```
○ 空き  ① 残りわずか  × 予約できません
```

**残席数の計算：**
- BinInfo.actualRemaining を使用
- 定員50%未満 → 残席数を数字で表示
- 0席 → × 表示

## タスク3: STEP 2 - 便選択

日付タップ後に表示。

### 便カード

```
┌─────────────────────────────┐
│ 🌅 昼便（タイラバ）         │  ← bin_settings.nameを表示
│ 05:00 出船  残り 8席        │
│ 📝 タイラバ・イカメタルをご持参ください │  ← noteがある場合のみ
│ ✅ キャスティングデッキあり  │  ← 便に関連する設備
│ ✅ タックル貸出（有料）      │
│                              │
│ [  この便を予約する  ]      │
└─────────────────────────────┘
```

**設備表示ロジック：**
- 昼便デフォルト：キャスティングデッキ・タックル貸出・クーラーボックス・血抜き・神経締め
- 夜便デフォルト：夜焚き用集魚灯・生け簀・海水循環装置
- リレー便：昼便＋夜便の両方
- facilities_overrideがある場合はデフォルトを上書き
- 設備が「なし」のものは表示しない

**1便のみの場合：**
STEP 2をスキップしてSTEP 3へ自動遷移。

**チャーター導線：**
```
貸切でのご利用はこちら →   ← テキストリンク（ページ下部）
```
タップするとチャーター問い合わせフォームへ遷移（STEP内で切り替え）。

## タスク5: STEP 3 - 予約フォーム

```
← 予約内容を入力

【確認】5月15日 昼便   ← 選択内容サマリー（変更不可）

お名前 *
[___________________]

電話番号 *
[___________________]

人数 *
[ 1名 ][ 2名 ][ 3名 ][ 4名 ]  ← ボタン選択

5名以上の方
[ －  5名  ＋ ]  ← スピナー（5〜定員まで）

釣り方（任意）  ← 便に釣り方未設定の場合のみ表示
[ ルアー ][ エサ ][ どちらでも ]

メッセージ（任意）
[___________________]

[   予約を申し込む   ]  ← 朱赤・全幅・64px以上

※ 申し込み後、船長から確認の連絡が届きます
```

**人数選択ルール：**
- 1〜4名：ボタン選択
- 5名〜定員：スピナー（5から開始）
- 残席未満のボタンは自動グレーアウト
- 定員超：選択不可

**釣り方の条件分岐：**
- bin_settings.fish_typesが設定されている → 入力欄を表示しない
- 未設定 → 任意で表示

**要電話連絡フラグの自動検知：**
メッセージ欄に「電話」「連絡」「確認」などのキーワードが含まれる場合、
bookings.needs_call: trueを自動設定し、needs_call_reasonにメッセージ内容を保存。

**送信後：**
SMSで乗船名簿用URLを送信（board_tokenを生成してbookingsに保存）。

## タスク7: 設備詳細ページ（新規）

reserve/[vesselId]/facilities/page.tsx を新規作成。

vessels.facilitiesの全項目をカテゴリ別に表示。

| カテゴリ | 項目 |
|---|---|
| 釣り道具 | タックル貸出・ライフジャケット貸出・ロッドホルダー・ロッドキーパー |
| 設備 | 駐車場・トイレ・クーラーボックス・生け簀・海水循環装置・電動リール用電源・集魚灯・電子レンジ・湯沸かし器・屋根日よけ・エアコン・魚群探知機 |
| 魚の処理 | 血抜き・神経締め・下処理 |
| 販売品 | 氷・餌 |
| 支払方法 | 現金・クレジット・PayPay・その他 |
| こだわり設備 | キャスティングデッキ・アンチローリングジャイロ・探見丸・自由入力項目 |

**表示ルール：**
- こだわり設備は設定項目がある場合のみカテゴリを表示
- 「なし」の項目はグレーアウトして表示（隠さない）
