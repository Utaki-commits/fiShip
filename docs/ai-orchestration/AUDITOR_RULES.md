## 判定基準

- **red**: 業務ロジック破壊・セキュリティ問題・絶対ルール違反など修正必須
- **yellow**: ルール逸脱・品質懸念・確認推奨
- **green**: 問題なし

## Architecture Auditor 判定ルール

### 🔴 Red（修正必須）

- Supabase操作で `vessel_id` による絞り込みがない（データ漏洩リスク）
- 環境変数の実値（APIキー、秘密鍵など）がコードやコメントに出現している
- `SUPABASE_SERVICE_ROLE_KEY` がClient Component側で使われている
- `'use client'` なしにブラウザAPIを使っている
- API Routeがエラー時にレスポンスを返さず処理を止めている
- 予約・キャンセル・削除の業務ロジックが確認なしで実行されている
- 既存のテーブル名・カラム名・APIエンドポイント名を推測で変えている
- App Routerの配置ルールを破っている（例: `src/app/` 外にページを作成）
- 単一コンポーネントが300行超
- src/配下以外への実装ファイル追加

### 🟡 Yellow（人間確認推奨）

- `NEXT_PUBLIC_` のない環境変数をClient Componentで参照している
- API RouteのHTTPメソッドが命名規則と合っていない（GET/POST/PATCH/DELETE）
- エラーハンドリングがなく、失敗時に無言で止まる可能性がある
- catchでエラーを握りつぶしている
- 未関係ファイルを変更している
- 既存の共通クライアント（`@/lib/supabase`）を使わず直接初期化している
- 同じロジックが3箇所以上に重複している
- propsのバケツリレーが3段以上

### ✅ Green

- 上記に該当しない変更

## UX Auditor 判定ルール

対象ユーザー: **30〜65歳の漁船船長（ITリテラシー低・屋外スマートフォン使用）**

### 🔴 Red（修正必須）

- 1画面に主要CTA（Call to Action）が複数ある
- `OCR`, `Webhook`, `API`, `DB`, `JSON`, `boolean` などのIT用語が船長向けUIに出ている
- タップ対象の高さが `44px` 未満（通常ボタン最低 `56px`、主要CTA推奨 `64px`）
- エラー時に画面が無言で止まる（処理中・エラー表示なし）
- 予約・削除などの破壊的操作に確認ステップがない
- フォントサイズが `14px` 未満で重要情報を表示している
- モバイル（390px）で主要CTAが画面外に出ている
- 意思決定が必要な主要CTAがファーストビュー外にある
  （スクロールしないとボタンが見えない状態）
- 予約・送信・確定などの主要アクションボタンが
  画面下部固定でも画面内固定でもなく
  コンテンツの下に埋もれている

### 🟡 Yellow（人間確認推奨）

- 1画面の主目的が複数ある
- 選択肢が5つ以上横並びになっている（原則4つ以下）
- ボタンの処理中状態（disabled + 処理中文言）が実装されていない
- エラー文が抽象的で「次に何を直すか」がわからない
- デフォルト値が設定されていないフォーム項目がある（定員4、出船05:00など）
- UI文言が英語になっている（ユーザー向け文字列）
- ローディング表示がない非同期処理がある
- 情報ブロックが1画面に5個以上

### ✅ Green

- 上記に該当しない変更

## UI Design Auditor 判定ルール

### 🔴 Red（修正必須）

- CSS変数（`var(--ocean)`, `var(--surface)` など）を使わずハードコードした色を新規追加している
- 編集ボタンを赤系にしている
- 削除ボタンを青系にしている
- ダークモードで文字が読めない色の組み合わせを使っている
- `border-width: 2px` を使っている（**0.5px が原則**、2px禁止）
- `font-weight: 700` を使っている（**400/500のみ許可**）

### 🟡 Yellow（人間確認推奨）

- `var(--border)` に近い色を独自に定義している
- カード構造（surface背景・border・角丸）に準拠していない新しいカードを追加している
- ボタンスタイルが既存ルールと異なる（主要CTA=ocean、編集=blue outline、削除=red）
- 未連絡の承認済み予約カードに左ボーダー強調がない
- 船長向け画面をPCダッシュボード風の横長レイアウトにしている

### ✅ Green

- 上記に該当しない変更

## 共通禁止事項（Architecture・UXどちらも指摘）

- FigmaにないUIを勝手に実装している
- 既存の文言・ステータス名（`満員`, `休船日`, `承認待ち`, `承認済み`, `お断り`, `キャンセル`）を別の文言に変えている
- 環境変数名を変えている
- 破壊的なgit操作やファイル削除を含んでいる
