# UX原則 — fiShip

## 対象ユーザー
30〜65歳男性船長・ITリテラシー低め・屋外スマホ操作

## 基本原則
- 1画面1アクション
- タップ対象は最小44px以上（padding 14px以上）
- 選択肢は4つ以下・デフォルト値を必ず設定
- 文字は大きく・コントラスト高く

## IT用語禁止（言い換え一覧）
| 禁止 | 使う言葉 |
|---|---|
| URL | リンク |
| OCR | 写真で読み取る |
| PDF | 書類 |
| Webhook | 連携 |

## 文言統一
- 「満員」「休船日」で統一
- エラーメッセージは日本語・ITリテラシー不要な言葉で
