# 乗船客UX DNA — fiShip

## 最重要目的
「行きたい日に釣りへ行けるか」を一瞬で理解させる。
空席認識速度を最優先とする。

## このUIは「空席視認UI」である
予約管理UIではない。乗船客はカレンダーを見て
「この日は空いているか」だけを知りたい。

## UI優先順位
1. カレンダー視認性
2. 空席状況の分かりやすさ
3. 予約CTA
4. 船情報
5. 詳細情報

## カレンダー表示ルール
- 空き：白背景（タップで予約へ）
- 残りわずか（定員70%以上）：薄赤背景
- 満員：赤背景・タップ不可
- 休船：グレー背景・タップ不可
- 過去日：グレーアウト
色で状態を伝えること。凡例は必ず表示すること。
文字情報より色を優先する。

## 禁止
- 管理画面風UI
- 情報過多
- 複雑な絞り込み優先
- 小さいカード乱立
- SaaS風ダッシュボード
- テーブルUI
- 多カラムレイアウト
- 予約CTAを長いスクロールの下に置く
- 空席視認性より絞り込みを優先する
